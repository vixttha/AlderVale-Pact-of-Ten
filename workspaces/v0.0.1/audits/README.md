# Audit Record Rules

Audit evidence may be stored here only when it is safe for the public repository.

- Record public repository revisions, public files, public issues/PRs, and public CI receipts.
- Keep private Notion page titles, links, IDs, contents, access grants, private agent settings, and personal details in the private workspace.
- Separate verified facts, observations, proposals, and unverified claims.
- Record the exact checkout SHA and actual checks; do not transfer a PASS result to a different revision without proving equivalence.
- Do not claim a live Notion setting, memory toggle, permission, or fresh-chat result unless it was directly verified.
- Do not publish secrets, credentials, private logs, screenshots, or private user data.

The initial integration audit is kept in the conversation and private coordination record. This public branch contains only the audit methodology and public-safe operating contract.
