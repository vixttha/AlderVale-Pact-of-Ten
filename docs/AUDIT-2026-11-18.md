# Launcher readiness audit — 2026-11-18

## Verdict and coverage

**NOT_READY for public distribution.** The existing owner-play launcher has a
verified Windows source-upgrade path, while this new launcher home contains
governance, design and a tracked backlog only. It contains no installer.

Game baseline: `5a7d0438e46582e625fc101efb6aa0f9e637c55e`. Test Vault baseline:
`89b2796df7dc6f4429da31591b7bb401b144f2ac`. This is a scoped launcher and release-readiness audit, not a fresh
line-by-line security review or gameplay acceptance of the entire game.
Results are bound to these snapshots; main can advance during work.

Method: direct connected GitHub reads of rules, launcher, manifest, workflow,
storage and server entrypoints; repository tree/release/issue inspection;
related PR and Vault test-source review; earlier same-session real local upgrade;
official vendor documentation. No third-party launcher binary was installed or
reverse-engineered. No physical macOS/Linux testing, credential inspection,
asset-rights certification or production account testing was performed.

## Real local Windows upgrade evidence

Earlier in this same task thread, the existing launcher executed
`node "./AlderVale Play/play.mjs" --install` against public GitHub main,
without --checkout or synthetic fetch substitution.

- Previous installed game: `fced4038c1dfa655c223d1bcbbdf3c18593b1e1f`.
- Fetched, built and installed: `38ba3e66f62e3607e23a5ed8d82fe625e770a1a5`.
- npm installed 484 packages; Vite 8.3.8 transformed 1,735 modules; build completed
  in 20.91 seconds with a nonfatal large-bundle warning.
- Process exit 0; launcher health and page checks completed before success.
- Independently read current.txt matched the target full SHA.
- dist/index.html SHA-256:
  `BC80F091EC9424D5129F045870FCED5D2797A1889B6952FBA5D1C63265536456`.
- A repeat identical install command exited 0 and reused the cached build.
- Previous build remained present; dedicated source checkout stayed clean.

This receipt is local and session-observed, not a hosted independent review.
It predates the newer audited main SHA. No upgrade to the newer main was run
during this branch bootstrap. It does not prove offline fallback, GUI gameplay,
save import, signed download verification, or a macOS/Linux installer.

## Release acceptance denominator

Public readiness is **0 completed platform installer/upgrade acceptance gates**.
Required proposed targets: Windows x64, macOS arm64, macOS x64, Linux x64.
The CPU scope and minimum OS versions await owner confirmation and native proof.

Required on each: clean install without developer tools, N-to-N+1 upgrade through
the actual signed feed, tamper rejection, interruption/full-disk recovery,
offline usable install, repair, save preservation/import, rendered game launch,
shutdown cleanup, platform identity/signing checks and owner acceptance.
Track these in #143 and #149 rather than translating existing green source CI
into public release readiness.
