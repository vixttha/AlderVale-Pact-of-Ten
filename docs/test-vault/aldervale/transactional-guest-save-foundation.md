Contract: a per-realm IndexedDB record holds format, positive safe revision, opaque raw string and first committed original raw string. Initialization requires null expected revision and missing record; updates require exact current revision. Same readwrite transaction checks and writes; only oncomplete reports success. An invalid stored record, missing store, unsupported open, quota failure or abort fails closed. No unlocked fallback; no deletion or restore API. Original bytes remain opaque, including historical serialized affinity IDs. IndexedDB transactional completion does not promise immunity to storage eviction, hardware failure, external deletion or uncooperative clients.

Public-runner acceptance: same browser context with independently opened pages; concurrent initialization and same-revision writes, exactly one winner, stale retry rejected; other realm unaffected, reload sees winner and original, v1 key unchanged; injected transaction abort/quota error leaves existing record untouched and permits same-revision retry; malformed record/invalid revision/unknown realm/unavailable factory rejected. Real browser module bundled from the source with existing esbuild dependency; synthetic same-origin HTML fixture avoids game/network/production authentication. Test failure evidence must be preserved. Run existing seven-job validation, Test Vault, Semgrep, policy, scoped graph and receipt checks as applicable. No gameplay acceptance inferred.

Remaining gates before real save cutover: full nested legacy validation and cross-reference checks; reviewed migration/restore state machine with immutable source and verified readback; reject divergent v1/v2 copies and interrupted imports; prove no live writer bypass and stale clients cannot silently reimport; integration of async writes with pending UI/action ordering and auth/realm switches, recovery for pending edits, real-world storage eviction/backup and explicit owner integration. No cloud or production migration. The confirmed ten schools stay unchanged.
