# Template adoption

Use [the versioned guide](../workspace/v0.0.1/GUIDE.md). A development consumer
pins the template source commit/version and verifies original/rendered bytes.
A Draft template is development source, not an approved redistributed release.

AlderVale-Launcher is the first specialization. Root instructions and AlderGate
identity must point to the rendered pair inside its v0.0.1 workspace. Its product
map must cover that pair and binding record. This template keeps independent
version history and Graphify evidence. Issue #152 tracks the setup.

No whole-branch merge, tool permission, deployment or player AI runtime is implied.
