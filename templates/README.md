# Blank asset contract

Copy asset.json to a new manifest for an approved asset. Required populated fields: asset_id (lowercase slug), reference {path,sha256} for an original approved PNG; additional_views array of identical objects; anatomy nonempty text; owner_scope nonempty scope reference; model exactly spar3d or sf3d; budgets {runtime_triangles, texture_px, max_minutes}. Each source file must be public-approved, accessible in this checkout, and verified. A manifest records scope but does not prove permission. Do not use the blank as a run request. Intake validation checks only file signature and digest, not full image decoding, license, or quality. Full image decode, upstream pins and license gates are P02/P03. All budgets are integer and positive; no more than 240 minutes or 4096 texture pixels under this initial guard.
