# C# guest save contracts

The Node fixture exporter captures the raw JSON written by AlderVale's real `saveGuestRealm` function for synthetic Breeze and Horizon players. A separate C# executable reads those bytes with `System.Text.Json` and checks exact contract values, types, and relationships. The guest writer runs with in-memory storage and blocked Firebase calls. The C# reader lives in the test suite.

| Case | Reference inputs and expected behavior |
| --- | --- |
| G28-008 | Two Breeze wizards and one Horizon wizard each have IDs matching the account index, realm and owner. Test controlled cross-realm and foreign-index changes. |
| G28-009 | Rowan begins with 110 XP at level 1 and 3,000,000,000 synthetic Florins to exercise exact integers beyond 32 bits. First Spark adds 90 XP, crosses the 147 XP threshold and leaves 53 XP at level 2, rank 1. Wallet is 3,000,000,110 Florins, 10 Honor Marks, 2 Bonding Seals and 7 Spell Shards. First Spark is complete and the separate Arbor counter is 1. The two untouched wizards retain their starter state. |
| G28-010 | Match creature records against the owning wizard, account and realm. Verify stage, species and talent lists in both realms and retain the active creature when it is the second member of a roster. Reject a foreign ownership reference and a foreign active selection. |
| G28-011 | A legacy-shaped v1 save omits `gallery` and `questWins`. Keep all the saved identity, wallet, XP, First Spark completion and creature relationship facts under test. Reject a missing required completion field. |
| G28-012 | Reject truncated JSON, numeric strings, fractional and unsafe integer balances, duplicate wizard IDs, a dangling wizard index and an orphan creature group. Check the diagnostic path, including array indices, for each rejection. |

The expected values come from reviewed v1 field definitions and fixed fixture inputs. The exporter does not produce the expected results. Keep the fixture inputs and independent expectations aligned when a contract change is approved. The older shape is intentionally generated by omitting optional fields on today's v1 format. Historical byte snapshots, arbitrary future version migration, browser storage recovery, signed-in cloud sync and production balances use separate evidence.

## Runner command

Use Node 24 and the .NET SDK version in `global.json`. The runner uses the SDK and standard library with no NuGet package sources or external test packages. From the repository root:

```sh
node tests/vault/csharp/export-guest-saves.mjs /tmp/aldervale-csharp-saves
cd tests/vault/csharp
dotnet --version
dotnet restore GuestSaveContracts.csproj --configfile NuGet.Config
dotnet run --project GuestSaveContracts.csproj --configuration Release --no-restore -- /tmp/aldervale-csharp-saves
```
