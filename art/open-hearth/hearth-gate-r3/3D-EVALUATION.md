# R3 material evaluation — candidate only

Owner authorized 3D stone monument, bronze plaque and cloth banner proofs; historical foundation accepted separately. Pinned BART 392d8d7a1c262227cba3c08d5577af38c74b4e25 (v0.0.3) and Blender 4.5.0 archive SHA from BART CI. No BART changes or arbitrary model-provided code execution in BART. A project-owned reviewed scene script creates original geometry using actual source masks (512px alpha sampled onto a closed 257x257 relief grid); BART converts each original BLEND to GLB and inspects it without overwrite. SVG geometry is unchanged; relief sampling and UV projection are finite-resolution approximations. No game runtime or final lock. Rendered files and actual receipts must be reviewed before acceptance. No external assets, API calls, local or paid runners. Artifact retention one day; reproducible sources retained. All three need legible open passage, coherent silhouette, plausible material and lighting, and visible flame at viewing distance. The numeric checks do not substitute for owner visual judgment.
