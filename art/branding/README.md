# AlderVale logo concept — Workmark v1

The owner selected [logo-workmarkv1.svg](logo-workmarkv1.svg) on November 15, 2026 as the approved logo concept for AlderVale: Pact of Ten. Use this exact workmark as the visual reference for future branding. Preserve the v1 file and give any later adaptation its own version.

The SVG embeds the original 2048 × 682 PNG. At the source dimensions the SVG renders pixel for pixel with the upload. The leaf wreath, four-point star, letterforms, gold edging, and subtitle are all part of the locked artwork. Approval covers the concept. A path-based redraw and in-game adoption are separate changes.
