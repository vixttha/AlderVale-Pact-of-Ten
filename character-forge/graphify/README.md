# Formwright Graphify / version evidence

The public main code graph is already generated by the repo's existing `.github/workflows/graphify.yml`. Its published receipt is **not** a Formwright-version graph.

The dedicated `.github/workflows/formwright.yml` verifies a **code-only graph at the exact candidate checkout**, using the existing pinned Graphify dependencies and source-verifying MCP scripts on a standard hosted runner. It prints the SHA, graph hash, node/edge statistics and MCP result in the Actions job summary. A code-only graph covers program source; it does not semantically map these Markdown template documents or prove cloth fit.

Formwright template version history is kept in the [version index](../versions/README.md), the [portable template](../template/v0.0.1/README.md), and the [draft workspace](../workspace/v0.0.1/README.md). For future **accepted** versions, store a verified graph and receipt in `graphify/versions/<formwright-version>/` only through a separate authorized promotion, keyed to source SHA. Until then, refer to hosted run receipts rather than inventing a permanent snapshot.

Never reuse ambiguous unprefixed global version tags for this HQ. Store no model API token or private Notion content in CI. Graph jobs must not deploy, tag, or release the game.
