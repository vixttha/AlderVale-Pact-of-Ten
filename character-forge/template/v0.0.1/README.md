# Formwright Agent Template v0.0.1 (portable draft)

A portable, copy-and-adapt operating template for a solo-owner character-systems work lane.

Files: [role contract](AGENT_TEMPLATE.md) and [operations/versioning](OPERATIONS.md).

This directory intentionally includes **no game name, race IDs, private links, account identifiers, asset paths or implementation code**. Project-specific names, permissions, decisions, rigs and tests belong in an adoption workspace separate from this template.

To adopt:
1. Read the target repository's authoritative instructions and actual owner scope.
2. Copy the template into the target's own namespaced work area and replace placeholders.
3. Validate policy, isolation, version provenance and tests before proposing a code PR.
4. Keep draft and accepted versions distinct; obtain owner acceptance before archiving.
5. Identify worker/host/actor and the exact source commit in every receipt.

The template does not create a new agent account, grant access, schedule background work or make release decisions.
