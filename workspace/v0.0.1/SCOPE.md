# v0.0.1 scope and acceptance

## Owner direction

Create a public pre-game launcher for AlderVale, with Windows, macOS and Linux
planned together. Maintain the work through GitHub Issues. The current task sets
up version management and Graphify before implementing the launcher.

[#145](https://github.com/vixttha/AlderVale-Pact-of-Ten/issues/145) and

## Setup acceptance

- Separate a mutable workspace from owner-approved immutable archives.
- Pin every mapped source to a full commit and complete file inventory.
- Generate a real Graphify graph, source outline and hash receipt for each entry.
- Rebuild and query maps through Graphify MCP on bounded public CI.
- Reject source/map drift, missing versions and changes to approved archives.
- Preserve main, Test Vault and README HQ; no paid operation or release implied.

## Product acceptance remains separate

No public-ready claim until real native clean-install and older-to-newer upgrade,
rendered play, save preservation, update authenticity and recovery checks pass
for every advertised target and the owner accepts publication.
