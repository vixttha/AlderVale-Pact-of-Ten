# Version Archive

Each accepted Notion Agent version is archived as a complete, byte-matched snapshot under `versions/vX.Y.Z/`.

Do not create or label an archive as accepted until the owner has reviewed the candidate, the exact source SHA is recorded, public-safety checks pass, and the owner explicitly accepts the version. Keep the editable work for each version in its matching `workspaces/vX.Y.Z/` directory. Never use the root HQ README as a test workspace.
