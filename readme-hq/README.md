# README HQ’s own versions

This folder tracks the front page at `/README.md` on the `readme-hq` branch. The [public game README history](../versions/README.md) has its own version numbers and changelogs.

**Current HQ version:** `v0.0.1`

- [Version history](versions/README.md) records one row per published HQ version.
- [Workspaces](workspace/README.md) links to the workspace for each HQ version.

For an HQ revision, work only in `readme-hq/workspace/<version>/`. Read other folders for context and check the diff against the starting commit before handing it back. Once the revision is accepted, promote it to the branch front page, archive an exact copy, and update this version pointer and the history in one commit. This folder stays on `readme-hq`.
