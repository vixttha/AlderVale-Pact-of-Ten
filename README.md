# AlderVale Universe HQ

Standalone project-specific storyworld workspace; do not merge wholesale into game main. No game runtime copied. This is an original AlderVale scaffold, not an installation or publication of the private reusable writing framework. Approved direction is separate from finished canon. The owner alone approves new canon, implementation, merges and releases.

Start with [registry](canon/registry.json), [world and story](canon/world-and-story.md), [decisions](DECISIONS.md), and [work queue](WORK-QUEUE.md). Game engineering stays on main; Element HQ owns schools and fusions; Character Forge owns race-model specifications; this branch owns narrative consistency and geography. No private planning, unpublished story secrets, personal information or credentials belong in public files. Maintain private reveal details separately. Use standard public GitHub runners only.
