# Launcher-Agent-Template

Reusable housekeeper/creator instructions for agents maintaining game launchers.
This is the template home; [AlderVale-Launcher](https://github.com/vixttha/AlderVale-Pact-of-Ten/tree/AlderVale-Launcher)
is its game-specific consumer. An instruction template is not a deployed agent.

No paid service, model API, schedule, signing authority, deployment or public game
release is introduced. A consumer pins a real source commit and full template
inventory; it renders project parameters and verifies the resulting bytes.
Template and product versions are independent. The first version is development
source pending owner review, not an approved redistributed release.
