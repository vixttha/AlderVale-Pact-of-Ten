# Quality gates and proposed budgets

The owner approves each asset contract. Default proposals, not owner-locked game budgets: master 100k–500k triangles where justified (not a minimum and not guaranteed by generators); runtime 10k–30k triangles; texture up to 4K master and 2K runtime; three LOD levels for animated creatures. Set per-asset actual limits and target device/profile before generation. More polygons do not imply fidelity.

Hard geometry: finite positions/normals/UVs, valid indices, zero repeated-index, duplicate and degenerate faces, no unused vertices; inspect manifold edge incidence, winding, components, self intersections and intended openings; no unapproved open geometry. Compare pre/post repair geometry and report face loss (historical conservative threshold 1% proposed; any exception requires review). Reimport exact exported GLB and repeat checks with independent implementation, Khronos errors zero and explicit warning disposition.

Visual master: actual matching camera views and silhouettes, annotated landmark error with calibrated thresholds, pose, proportions, limb count/attachments, eye/ear/tail shapes, distinctive motifs, material roughness/metalness, albedo and intended emission. Lit reference colors are not intrinsic albedo. Do not substitute a procedurally plausible creature for the approved design. Record unknown surfaces and owner-approved resolution. Require owner visual acceptance of exact master digest before optimization.

Runtime: asset-local axes/scale/pivot, valid UV coverage/padding and texture readback, PBR channels, consistent skin weights and bone references, expected clips and sampled deformation/contact, LOD budgets, frame time and memory on specified actual browser/device. CPU software WebGL runner is a smoke test, not real device performance. Render seven actual imported GLB angles plus optional native 4K views. Compare master/runtime renders and silhouette. Explicit owner acceptance separate from all automated checks.
